# 2026-10-20

## Sitio "PoliMusic" - clon de YouTube Music en ASP clásico (VBScript)
- Creado sobre la BD existente `BDD_PoliMusic` (SQL Server localhost:1433, usr_polimusic / Politecnica1).
- Restricción respetada: no se crearon tablas nuevas, solo se usan las del script `BDD_PoliMusic.sql`
  (TBL_SONG, TBL_USER, TBL_ALBUM, TBL_ARTIST, TBL_TRACKLIST, TBL_PLAYER, TBL_PLAYLIST,
  TBL_PLAYLIST_SONG, TBL_CATALOG).
- Páginas .asp: login.asp, logout.asp, index.asp, songs.asp, playlists.asp, albums.asp,
  admin_songs.asp / admin_song_form.asp / admin_song_save.asp / admin_song_delete.asp,
  admin_users.asp / admin_user_form.asp / admin_user_save.asp / admin_user_delete.asp,
  play_counter.asp.
- Includes en `includes/`: bootstrap.asp (connection + auth + encoding), connection.asp (ADO + helpers
  PM_Query/PM_Execute/PM_SQL/PM_Html/PM_Path/PM_Cover/PM_If), auth.asp (PM_RequireLogin / PM_RequireAdmin),
  header.asp, footer.asp (reproductor flotante), songlist.asp (Sub PM_RenderSongList).
- Roles: USER_TYPE 0 = normal, 1 = admin (etiquetas desde TBL_CATALOG, padre '1'). CRUD solo para admin.
- Paleta: azul #2E6BFF + rojo #FF2E4D sobre azul noche (#070B18 / #111834); degradado de marca azul→rojo.
- Assets copiados de `SongFilesAndImages_resources` a `songFiles/`, `userImages/`, `playlistImages/`,
  `albumImages/`. Como el script de BD referencia 5 mp3 y solo existía `bensound-adventure.mp3`,
  se duplicó ese audio con los nombres bensound-dreams/energy/scifi/tomorrow (reemplazables).
- Reproductor: barra inferior fija (js/app.js) con cola, next/prev, barra de progreso, volumen y
  contador de plays vía play_counter.asp.

## Lecciones / decisiones técnicas
- VBScript no acepta `IIf` con estos argumentos (Type mismatch 'IIf') → se creó `PM_If(cond, v, f)`.
- `Const` en VBScript no admite concatenación multilínea → cadena de conexión en una sola línea.
- No se usa `Option Explicit` (evita 500 por variables sin declarar); aun así se declaran con Dim.
- Verificación: IIS Express (`iisexpress /path:<raiz> /port:8099`) + Invoke-WebRequest.
  Se validó login, bienvenida, Song List (5 filas), CRUD alta/edición/baja de canciones y usuarios,
  bloqueo de CRUD a rol normal (redirect index.asp?msg=denied), logout y recursos estáticos (200).

## Arranque / parada (añadido después)
- Scripts en la raíz: `start_polimusic.bat` (lanza IIS Express en ventana nueva + abre el navegador)
  y `stop_polimusic.bat` (taskkill /IM iisexpress.exe /F). Puerto por defecto 8099.
- Comando manual equivalente:
  `"C:\Program Files\IIS Express\iisexpress.exe" /path:"<raíz del proyecto>" /port:8099`
- Detener: Ctrl+C en la ventana de IIS Express (responder S) o `taskkill /IM iisexpress.exe /F`.
- Verificado: ejecutar start_polimusic.bat deja http://localhost:8099/login.asp en HTTP 200.
